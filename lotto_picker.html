PCSO 2-Ticket Protocol Picker v2.4 · 2026-09-23 (r7)

Pick a date → see which games draw that night (9 PM PHT), the last official result, the posterior-predictive tickets, and a low-popularity random pair. Tickets A/B are the fixed posterior sets per game (they do not change per click); the button regenerates the random pair C/D.
Model equations — M₀/M₁ and model averaging (tap to expand)
Model M1: 6-without-replacement product-weight draw, fw(S) = ∏i∈S wi / e6(w); inclusion πi = wi e5(w−i) / e6(w), ∑iπi = 6; prior w ~ Dirichlet(a=100) fixed a priori
Prediction: S* = argmax P(next = S | data); R = C(n,6)·E[fw(S*) | data]; under the uniform model M0 every rule has R = 1 and Δ = 0 exactly
Model average (equal prior odds): Rmix = 1 + (R−1)/(1+BF01); credible intervals are on Rw(S*) = C(n,6) fw(S*) and condition on M1(100)
Two distinct tickets: P(either wins) = [R(A)+R(B)]/C(n,6) — 2/C(n,6) under M0
Headline numbers and evidence status (tap to expand)
Numbers, as the mathematics gives them (fitting run registered 2026-09-21, pinned at 994 official-verified draws through 2026-09-20, per-game fitting T = 198/199/199/199/199; canonical file now 999 draws through 2026-09-22; corrected per two gpt-6-astra reviews): conditional on M1(100), the maximum-predictive six-set of each game carries R = 1.48–1.64 on P(jackpot) versus a uniform pick, with 95% credible intervals whose lower ends are 0.97–1.08. At a=100 the Bayes factor BF01 is 0.29–1.15: four of the five games lean toward unequal weights (most in 6/55), while 6/42 now leans weakly toward uniform; at a=10 the direction reverses (BF01 184–18,359), so the evidence is weak and prior-sensitive. Model-averaged multipliers 1.22–1.50. Neither tested order-1 persistence statistic rejects at Bonferroni 0.01 (other transition alternatives were not exhausted). No selection rule differed from uniform in the draw-paired backtest after Holm (min Holm p 0.055; adaptive rules calibrated with tickets fixed, not by history replay). Popularity index: winning-bet counts scale by 1.68 [1.44, 1.95] per within-game SD at equal game and jackpot (HC1) — an association of counts; it establishes neither a draw-probability effect nor a calibrated payout gain.

2 · Next-draw posterior predictive (product-weight model)
Next-draw posterior (src/pcso_next_draw_posterior.py → results/pcso_next_draw_posterior_2026-09-21.json): likelihood ∏i wici / e6(w)T (the e6 normalizer is what a multinomial-on-counts model omits, and Dirichlet conjugacy does not survive it); posterior expectations by importance sampling from Dirichlet(a+c) with weights z(w)−T, z(w) = e6(n·w)/C(n,6), 200,000 samples per game (effective size ≥ 195,000). BF10(a) = n6T Γ(na)/Γ(na+6T) ∏i Γ(a+ci)/Γ(a) · EDir(a+c)[z(w)−T]. The conditional probability that some ball's inclusion deviates more than 10% from 6/n is ≈1 under M1(100) in every game — a property of the conditional model, not evidence for it; at equal model odds it is 0.47–0.78; under a=1000 the independent reconstruction reports 0.012–0.029. Static-weight inference: it does not estimate a changing "hotness" or Markov mechanism. Independent reconstruction by Codex gpt-6-astra (results/codex_review_2026-09-06.md) uses the same model and reaches the same conclusions; its point estimates differ at the third decimal and its order-1 test uses likelihood-ratio ordering, whereas this page's overlap test is an exact absolute-deviation test on the total overlap of consecutive draws. The 6/42 sixth-place tie is gone this run; sixth-place ties (6/45 with 25; 6/58 with 23, 30, 34) are shown on the tickets where applicable.

Selection correction and model weight (src/pcso_picker_calibration.py → results/pcso_picker_calibration_2026-09-21.json; docs/RESULTS_PCSO_PICKER_THEOREM_2026-09-23.md): tickets A and B are chosen by ranking the same counts that R is computed from, so the raw R is inflated even under uniform draws. Re-running the predictor on 1,000 uniform histories per game gives exp E0[log R] = 1.44–1.45 for A (first order: exp(σcs6/(a+c̄)), s6 = expected sum of the top six of n standard normals); per evaluation-protocol rule H5 the page reports Rc = exp(log R − E0[log R]) = 1.02–1.13 (A) and 1.00–1.03 (B); null tail p for A 0.012–0.32, none below 0.05 after Holm over five games. The weight of the tilted model is π1 = e/(1+e), e = the held-out (post-freeze) prequential evidence of the same a=100 model (0.49–3.20 per game, product 1.17). The page's predictive probability is the normalised model-averaged law qmix = (1−π1)p0 + π1q1, i.e. Rmix = 1 + π1(R − 1); Rc is a null-centred diagnostic of how much of R is selection, not a probability (referee Codex gpt-6-astra, 2026-09-23; registration amendment v2 §D). Walk-forward check over 844 draws (tickets built from earlier draws only): no rule matches more than uniform after Holm over six looks (minimum 0.25), and no ticket matched a full draw.

6 · Random low-popularity pair (conscious-selection index)
Random low-popularity pair: a uniform 12-number sample by Fisher–Yates with the browser's cryptographic RNG (rejection sampling removes modulo bias), split into two disjoint tickets; the pair is accepted when both tickets' conscious-selection index is at or below the estimated 40th-percentile cutoff of the uniform CSI distribution for that pool (full-precision cutoffs from results/pcso_strategy_backtest_2026-09-06.json: 6/42 0.024313725 · 6/45 0.009090909 · 6/49 0.028184282 · 6/55 0.017210952 · 6/58 0.003333333; CSI is discrete, so the accepted fraction is not exactly 40%). If no pair is accepted within 20,000 proposals the page says so instead of showing rejected tickets. CSI ingredients: excess share of numbers ≤31, ≤12 and {1,3,5,7,9,11,12,13}; flags for arithmetic progressions, runs, common divisors, single last digit, single parity; weights are literature-motivated declared constants (Cook–Clotfelter, Stern–Cover, Simon, Farrell et al., Baker–McHale, Roger–Broihanne, Polin et al. motivate the ingredients; the decimal weights are the lab's declaration, not estimates from those papers). Same function as src/csi_popularity.py (parity self-test below). PCSO validation (984 draws, CSI standardized within game, winners permuted within game): T1 = +0.74 sd (raw p 5e-05), T2 = +0.16 rank correlation (raw p 1e-04), Holm p = 1e-04 both; Poisson pseudo-MLE with game effects and HC1 sandwich: winning bets ∝ exp(0.52·zCSI) conditional on game and jackpot, count ratio per SD 1.68 [1.44, 1.95]. Ticket sales are not published, so this is a count contrast at equal game and jackpot, not popularity per purchased bet. The zCSI shown per ticket uses the fitted within-game mean/SD of the observed draws (the covariate the slope refers to). G0 exploratory.

8 · Expected-value model and draw schedule
The sales input was replaced by per-game estimates N̂ = W·C(P,6)/T from the official winner counts W over T draws in the 1,016-row official file (exact Poisson 95% CI; E[winners] = N/C(P,6) holds exactly for uniform draws regardless of number popularity); constant-sales-across-draws is an approximation, as sales typically rise with the jackpot.

EV model (uniform-draw scenario M0, all tickets and tiers on the same model): hypergeometric tiers hk = C(6,k)C(n−6,6−k)/C(n,6); official Feb-2026 matrix (ticket ₱25; Category II/III fixed pools shared per winning bet, Category IV fixed); co-winner count K ~ Poisson(N·hk) under an assumed uniform, independent competitor-bet model (the results estimate no lower-tier co-winner distribution); the 20% tax is applied to each realized individual share above ₱10,000 inside the expectation, E[T(A/(1+K))]. The posterior jackpot-probability multipliers Rmix(A), Rmix(B) are shown beside the tickets as separate information and are not folded into the EV. The CSI count contrast eβz(S)/EU[eβz] is shown per ticket as an association only; it is not used as a sharing probability. Jackpot defaults = last official draw (Sep 21–22, 2026); edit per draw night. N is an assumption.
